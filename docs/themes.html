Themes & Mods

Make it yours.

Themes change Gallium's colours, wallpaper and feel. Mods restyle the interface itself. Every file here is checked and virus-scanned before it's listed.

Browse the galleryHow to installMake your own
Checked

Themes are only colours, a few settings and a picture. Mods are only CSS. Anything that tries to load files from the internet, run code or hide the whole window is rejected.

Virus-scanned, twice

Every file is scanned with ClamAV whenever it changes and every week with fresh definitions. When you install it, Gallium scans it again with Microsoft Defender on your PC.

Your call

Gallium shows exactly what a file changes and asks before installing. If a mod ever breaks things, press Ctrl Shift M to turn every mod off.

Only install mods from people you trust. Mods can't run code, read your tabs or go online, but they can change how things look, for example hide or imitate parts of the address bar. Scans catch known threats, not every trick. Files from anywhere other than this page haven't been reviewed.

One click. Really.

Pick whichever way is easiest for you. Every way ends at the same place: Gallium shows what the file does, scans it, and asks before installing.

  2. Or go to Settings › Themes & Mods › Import a file.
  3. Check what it does, then click Install.
After installing a theme

It switches on straight away, with an Undo button if you change your mind. Swap looks any time from the Customize button in the corner of the home screen, or in Settings › Themes & Mods.

After installing a mod

It's on straight away. Turn it on or off, or remove it, in Settings › Themes & Mods. If anything looks wrong, press Ctrl Shift M to switch every mod off at once.

Nothing happens when I double-click the file

Install the latest Gallium from this site first; its installer teaches Windows to open these files with Gallium. You can also right-click the file, choose Open with, then Gallium. Or just drag the file onto Gallium's window.

Windows says the file might be harmful

Windows says that about many downloaded files. Theme and mod files are plain text that Gallium checks and scans with Microsoft Defender before anything is installed. If Gallium's check or scan fails, it won't install the file.

How do I go back to how things looked before?

For a theme, click Undo right after installing, or pick another look from the Customize button or Settings › Appearance. For a mod, switch it off or remove it in Settings › Themes & Mods.

Can a mod harm my computer?

Mods are only CSS, so they can't run code, read your tabs or reach the internet, and Gallium blocks anything that tries. They can still change how Gallium looks, so only install mods from people you trust.

Make your own

Design a theme in minutes.

The Theme Studio in Gallium shows every change live on the real browser.

1
Open the Studio

On the home screen, click the Customize button in the corner, then Theme Studio. Or go to Settings, Themes & Mods.

2
Pick and tweak

Style, light or dark, two colours, an accent, font, corner roundness and a wallpaper, even your own photo.

3
Save and share

Save it, then Export to get a .gtheme file. Anyone with Gallium can install it by opening or dragging it in.

The rules. Colours are written like #a1b2c3. Styles are gradient, apple or glass. The wallpaper is a built-in name or an embedded JPEG, PNG or WebP picture up to 5 MB. Mods are CSS up to 100 KB, with no @import, no outside url(), nothing that hides the whole window. To get yours listed here, open a pull request adding it to docs/packages; it's checked and scanned automatically.

Virus scans use ClamAV (on GitHub) and Microsoft Defender (in Gallium). They find known threats but can't promise a file is safe. Fingerprints can be looked up on VirusTotal.
